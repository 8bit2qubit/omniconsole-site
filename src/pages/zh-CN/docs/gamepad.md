OmniConsole 完整支持 **Xbox 兼容（XInput）控制器**操作。

在手柄上按 **Xbox 键**可打开 **Game Bar** 界面，长按则打开**任务视图**。

## 平台设置界面

| 输入 | 系统平台 | 自定义平台 |
|---|---|---|
| **十字键 / 左摇杆** | 四向焦点导览 | 四向焦点导览 |
| **A 键** | 选取 | 选取 |
| **B 键** | 退出 | 退出 |
| **LB / RB** | 切换分类选项卡 | 切换分类选项卡 |
| **Y 键** | — | 新增自定义平台 |
| **X 键** | — | 编辑聚焦的平台 |
| **☰（Menu）** | 设为默认并立即启动¹ | 设为默认并立即启动¹ |

¹ 于 Xbox 模式 (FSE) 中

## 猫又模式

把手柄变成鼠标与键盘，还能随每个应用量身定制。开箱即有 **OmniNav** 与**经典**两种对应方式，还可自己定义第三种**自定义**布局（专业版）。光标速度可于设置中调整。

| 按键 | OmniNav | 经典 |
|---|---|---|
| 左摇杆 | 光标 | 滚轮 |
| 右摇杆 | 滚轮 | 光标 |
| A | 鼠标左键 | Enter |
| B | 鼠标右键 | Esc |
| X | Page Down | Page Down |
| Y | Page Up | Page Up |
| LB | Ctrl+Shift+Tab | Tab |
| RB | Ctrl+Tab | 鼠标左键 |
| LT | Esc | Shift+Tab |
| RT | Enter | 鼠标右键 |
| LS | Shift+Tab | — |
| RS | Tab | — |
| 十字键 | 方向键 | 方向键 |

### 开启 / 关闭

**开启 / 关闭**切换。开启时你自定义的配置文件优先接管，下列应用则使用内置映射（同样可自定义）：Edge、Chrome、Firefox、Opera、Brave、Epic Games Store、EA Desktop、Playnite 桌面版、文件资源管理器、Windows 文件选择器、打开方式对话框、Windows Installer、Steam、Discord、应用安装程序，以及一系列 Windows 内置工具与控制面板对话框。其中以管理员身份运行的程序（例如任务管理器）与屏幕键盘还需要管理员应用支持（专业版）。

可于 OmniCharm Game Bar 小组件切换。ROG Ally 家族具备内置手柄映射，猫又模式在那里会让路；专业版可为这类主机开启。

### 各应用映射

有些游戏只认键盘与鼠标，没有原生手柄操作。猫又为这类应用编一道咒，将 XInput 输入位（A/B/X/Y、LB/RB、LT/RT、LS/RS、十字键、左摇杆、右摇杆）重新映射为键盘、鼠标或光标动作，让它们也能纯手柄游玩。每道咒还能以猫又冲刺提高映射服务优先级、为任一按键开启长按连发，并拦截应用自身的原生手柄信号，避免双重输入。

于 OmniCharm 小组件点选 **“自定义此应用的手柄映射…”** 进入编辑器。

| **Y 键** | 在搜索框与列表间切换焦点 | — |

### 自定义控制器布局（专业版）

在 OmniNav 与经典之外，你可以自己定义一套默认布局。于**设置 → 高级 → 猫又 → 控制器预置布局**选择**自定义**，再点击 **编辑…** 编排手柄的输入位。

它随即成为所有应用的起点：内置映射覆盖的应用立即套用，新增的应用配置文件也从它开始。OmniCharm 小组件同样能切换到它。

### 管理员应用支持（专业版）

Windows 里有些应用和游戏只能以管理员身份运行，管理员应用支持让手柄映射也能作用于这类应用。

在**设置 → 高级 → 猫又**点击**安装**并通过管理员授权，猫又模式就此接手这类应用，OmniCharm 小组件也能为它们打开映射编辑器。

## OmniCharm 小组件

OmniCharm Game Bar 小组件提供游戏中的快速访问：

- **任务视图**、**Xbox 库**与 **Steam 叠加界面**的一键快捷方式。
- 切换**长按 ☰** 打开 Steam 游戏叠加界面。
- 切换**猫又模式**、更改控制器布局（**OmniNav / 经典 / 自定义**）、调整光标速度。
- 通过 **“自定义此应用的手柄映射…”** 按钮，为前台应用打开**猫又**各应用手柄映射编辑器；设置好管理员应用支持后，以管理员身份运行的应用同样适用。
