When launched outside XBOX Mode (FSE) (e.g., from the Start Menu), OmniConsole automatically triggers the XBOX Mode (FSE) entry dialog. Under Settings → Advanced → XBOX Mode (FSE) you can have Windows ask every time, restart for optimized performance, or start right away. The confirmation on the way back to the Windows desktop is yours to keep or leave out as well.
