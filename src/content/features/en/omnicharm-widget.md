A Game Bar widget for in-game quick access — open Task View, the XBOX Library, File Explorer, or the Steam Overlay in one tap. File Explorer opens straight to This PC, and Nekomata Mode's built-in mapping already covers it, so you browse and open your files with the gamepad alone. Also toggles Nekomata Mode, controller layout, cursor speed, and the long-press ☰ shortcut for the Steam In-Game Overlay. It opens the per-app mapping editor for the foreground app too, including apps that run as an administrator (Pro). Its Overlay tab adjusts RivaTuner Statistics Server's on-screen display while a game is running (Pro).
