A Game Bar widget for in-game quick access — open Task View, the Xbox Library, or the Steam Overlay in one tap. Also toggles Nekomata Mode, controller layout, cursor speed, and the long-press ☰ shortcut for the Steam In-Game Overlay. It opens the per-app mapping editor for the foreground app too, including apps that run as an administrator (Pro). Its Overlay tab adjusts RivaTuner Statistics Server's on-screen display while a game is running (Pro).
