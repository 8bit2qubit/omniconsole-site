Adjust RivaTuner Statistics Server's on-screen display from inside OmniConsole. Under Settings → Advanced → Performance Overlay you can turn the on-screen display on or off, show framerate statistics, add a shadow behind the text, scale it up, and set a framerate limit. The OmniCharm widget carries the same controls on its Overlay tab, so they are within reach while a game is running. Requires Administrator App Support and RivaTuner Statistics Server.
