These consoles ship with the manufacturer's own gamepad mapping, and Nekomata has always deferred to it. Pro makes that a choice: turn it on under Settings → Advanced, then set Control Mode to Gamepad in Command Center. Everything Nekomata does on your other consoles she does here too, with the same layouts, the same per-app charms, and the same editor you already know. It starts out off, and asks for confirmation the first time.
