遊戲中快速存取的 Game Bar 小工具：一鍵開啟工作檢視、Xbox 媒體櫃、檔案總管或 Steam 內嵌介面。檔案總管直接開啟本機，而貓又模式的內建映射涵蓋它，瀏覽與開啟檔案全程用手把就行。並可切換貓又模式、控制器版面、游標速度，以及長按 ☰ 開啟 Steam 遊戲內嵌介面。也能為前景程式開啟各程式映射編輯器，包含以系統管理員身分執行的程式（專業版）。切到疊加層分頁，遊戲進行中也能調整 RivaTuner Statistics Server 的螢幕顯示（專業版）。
